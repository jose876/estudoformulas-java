\# Estudo de Fórmulas Matemáticas em Java



Projeto desenvolvido em Java para praticar lógica de programação, estruturas condicionais, laços de repetição, entrada de dados e cálculos matemáticos.



\## Funcionalidades



\* Cálculo de seno.

\* Cálculo de cosseno.

\* Cálculo de tangente.

\* Cálculo do Teorema de Pitágoras.

\* Menu interativo no terminal.

\* Entrada de dados pelo usuário.



\## Tecnologias utilizadas



\* Java

\* Scanner

\* Switch

\* While

\* Métodos da classe Math



\## Como executar



1\. Tenha o JDK instalado.



2\. Clone ou baixe este repositório.



3\. Abra o terminal na pasta do projeto.



4\. Compile o arquivo:



&#x20;  `javac estudoformulas.java`



5\. Execute o programa:



&#x20;  `java estudoformulas`



\## Objetivo



Projeto de estudos desenvolvido para fortalecer os fundamentos de Java e a lógica de programação.
